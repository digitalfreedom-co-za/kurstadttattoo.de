# Eingang für neue Galerie Fotos

Legen Sie hier neue Tattoo Fotos ab: oben rechts Add file, dann Upload files, Fotos hineinziehen, unten Commit changes.

- Am 1. jedes Monats kommen alle Fotos aus diesem Ordner von selbst in die Galerie der Website, ganz oben unter Neu im Studio.
- Fotos als JPG, mindestens 1200 Pixel an der langen Seite, höchstens 25 MB. HEIC Fotos werden nicht verarbeitet.
- Nur Fotos, mit denen der Kunde einverstanden ist.
- Dieser Ordner ist öffentlich. Schalten Sie in der Kamera das Speichern des Standorts aus.
- Eigener Bildtext: eine Textdatei mit demselben Namen wie das Foto, zum Beispiel IMG_1234.txt zu IMG_1234.jpg. Erste Zeile Deutsch, zweite Zeile mit EN: davor Englisch.
- Bleibt ein Foto nach dem Monatsersten hier liegen, konnte es nicht verwendet werden.

Die ganze Anleitung mit Bildern: [docs/galerie-anleitung.md](../docs/galerie-anleitung.md)
